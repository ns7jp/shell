# 05. テスト仕様

## テスト方針

自動テストは一時ディレクトリだけを使い、rootや実サーバーを必要としません。実環境テストは別に記録し、自動テスト成功だけで本番動作を保証しません。

## テストケース

| ID | 対象 | 条件 | 期待結果 | 種別 |
|---|---|---|---|---|
| T-01 | 全スクリプト | `bash -n` | 構文エラーなし | 自動 |
| T-02 | backup | 正常設定、ドライラン | 終了0、ファイルなし | 自動 |
| T-03 | backup | 正常設定、execute | 終了0、読めるtar.gz | 自動 |
| T-04 | backup | `SOURCE_DIR=/` | 終了2、拒否理由あり | 自動 |
| T-05 | audit | CPUしきい値101 | 終了2、範囲エラー | 自動 |
| T-06 | audit | 存在しないサービス | 終了1、WARN | 手動 |
| T-07 | rotate | 期限を超えた練習ログ | 圧縮後に元ログ0バイト | 手動 |
| T-08 | restore | 作成済みアーカイブ | `diff -r` が終了0 | 手動 |
| T-09 | schedule | cron/systemd timer | 指定時刻に1回実行 | NOT RUN |
| T-10 | production | 本番相当容量 | 性能・容量条件を満たす | NOT RUN |
| T-11 | backup | SOURCE_DIR未定義 | 終了2、項目名を表示 | 自動 |
| T-12 | report | OKログ | 終了0、件数を持つJSON | 自動 |
| T-13 | report | WARNログ | 終了1、総合判定WARN | 自動 |
| T-14 | report | 不正形式 | 終了2、JSONを作成しない | 自動 |
| T-15 | 演習採点 | 全問に模範解答を配置 | 全問が終了0（合格） | 自動 |
| T-16 | 演習採点 | 全問に誤答例を配置 | 全問が終了1（不合格） | 自動 |
| T-17 | 演習採点 | 異常系（ID不明・作業場なし・答案なし） | 終了2、理由を表示 | 自動 |

## 実行方法

```bash
make syntax
make test
make lint
make lab-lint        # 演習パックのShellCheck
make lab-selfcheck   # T-15 / T-16 / T-17（演習パックの採点器）
```

T-16 は「採点器が常に合格を返す」という最も気づきにくい欠陥を防ぐためのテストです。詳細は[演習パックの採点設計](16-exercise-grading-design.md)を参照してください。

## 証跡テンプレート

```text
テストID:
日時・タイムゾーン:
実行者:
環境(OS/Bash/commit):
実行コマンド:
期待結果:
実結果:
終了コード:
判定(PASS/FAIL/NOT RUN):
ログまたはスクリーンショット:
備考・課題ID:
```

FAILを隠してPASSに変更しないことが大切です。修正後は新しい実行記録を追加し、どのコミットで直ったかを残します。
