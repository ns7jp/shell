# 09. 用語集・チートシート

## 重要用語

| 用語 | ひとことで | この案件の例 |
|---|---|---|
| シェル | コマンドを受け取る窓口 | Bash |
| シェルスクリプト | コマンドを順番に記述したファイル | `backup.sh` |
| 標準出力 | 通常結果の出力先 | INFO、OK |
| 標準エラー | エラー用の出力先 | ERROR |
| 終了コード | 成否を数値で伝える値 | 0、1、2 |
| 絶対パス | `/` から始まる完全な場所 | `/var/backups/app` |
| ドライラン | 変更せず予定だけ確認 | `--execute` なし |
| 冪等性 | 繰り返しても意図した状態になる性質 | 保存先の `mkdir -p` |
| 世代管理 | 複数時点のバックアップを残す | 日時付きtar.gz |
| ローテーション | 古いログを圧縮・削除する運用 | `rotate_app_logs.sh` |
| フェイルクローズ | 判断不能なら安全側で停止 | 危険パスを終了2で拒否 |
| 証跡 | 後から確認できる実行記録 | コマンド、日時、ログ |
| JSON | 機械でも読みやすい構造化データ | `audit_report.py` の点検証跡 |
| 原子的置換 | 完成したファイルを一度に差し替える | 途中のJSONを残さない |

## 調査コマンド

```bash
pwd                         # 現在地
id                          # 実行ユーザーとグループ
ls -ld PATH                 # 所有者と権限
namei -l PATH               # パス途中の権限
df -hT                      # ファイルシステムの空き
du -sh PATH                 # 対象容量
systemctl status SERVICE    # サービス状態
journalctl -u SERVICE       # サービスログ
tar -tzf ARCHIVE.tar.gz     # 圧縮内容の確認
echo "$?"                   # 直前の終了コード
```

## 5語の暗記法

**受ける・疑う・動かす・確かめる・伝える**

1. 引数と設定を受ける。
2. 値、権限、対象を疑って検証する。
3. ドライラン確認後に処理を動かす。
4. 成果物とサービス状態を確かめる。
5. ログと終了コードで結果を伝える。

## 作業前チェック

- [ ] ホスト名、環境、実行ユーザーは正しいか
- [ ] 対象と除外対象を声に出して確認したか
- [ ] バックアップまたは復旧方法はあるか
- [ ] ドライランの表示は意図どおりか
- [ ] 影響時間と承認者は明確か

## 作業後チェック

- [ ] 終了コードを直後に記録したか
- [ ] 成果物を読み直したか
- [ ] サービスを利用者視点でも確認したか
- [ ] ログに秘密情報が含まれていないか
- [ ] 未実施項目をNOT RUNとして残したか
