# E20 デバッグ記録

バグ3種は「引用符・終了コード・パイプ」です。3本それぞれについて、症状・原因・対処を書きます。

## b1.sh

- 症状: 空白を含むディレクトリ名を渡すと、余計なディレクトリが増え、`ambiguous redirect` で終了コードが1になりました。
- 原因: `mkdir -p $target` と `> $target/report.txt` で変数を引用符で囲んでおらず、空白の位置で2語に分かれていました。
- 対処: `mkdir -p -- "$target"` と `>"$target/report.txt"` のように、変数展開をすべて `"` で囲みました。

## b2.sh

- 症状: 壊れたアーカイブを渡しても「アーカイブは正常です」と表示し、終了コードが0のままでした。
- 原因: `tar` の後ろに `log WARN` を挟んでから `status=$?` を読んでおり、直前の `log` の終了コード0を受け取っていました。
- 対処: `status=0` としてから `tar ... || status=$?` の形にし、対象コマンドの直後で終了コードを受け取りました。

## b3.sh

- 症状: 壊れたアーカイブを渡しても一覧作成に成功したことになり、終了コードが0のままでした。
- 原因: `set -Eeu` に `pipefail` が無く、パイプの最後の `sort` が成功するとパイプ全体が成功扱いになっていました。
- 対処: `set -Eeuo pipefail` に直しました。`|| true` で握りつぶさず、失敗を失敗のまま伝えます。
