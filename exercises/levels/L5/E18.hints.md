## H1 骨のどこか

骨9要素の9番目「ログと終了コード」だけの問題です。
`docs/05-test-plan.md` の証跡テンプレートを開き、上から9項目をそのまま9行にします。

## H2 使う記号か関数名

日時は共通ライブラリの `timestamp` 関数が使えます。実行者は `id -un`、環境は `uname -sr` です。
9行はまとめて `printf '%s\n' "1行目" "2行目" ...` で出せます。

## H3 ほぼ答えの1行

```bash
if ((status == 0)); then verdict=PASS; else verdict=FAIL; fi
```

この `$verdict` を最後の「判定」の行に入れます。`PASS` と直接書いてはいけません。
