# E16 3段階の終了コードを配る（写経A）

## 1. 一行目標

この問題で新しく覚えることは1個だけです。**終了コードは 0 / 1 / 2 の3段階で配ります。**

## 2. 3行解説

- 警告を数える箱を1つ持ちます。`log WARN` を出すたびに `warnings` を1増やします。
- `warnings` が1件以上なら `exit "$EXIT_WARNING"` で終了1、0件ならそのまま進んで終了0です。
- 検証に失敗したときは `die` が終了2で止めます。`1` という数字は自分では書きません。

## 6. 手順

1. `cat -n scripts/server_audit.sh | sed -n '92,96p'` で見本の5行を表示します。
2. その形を `report.sh` の `# TODO:` の2行と置き換えて写します。件数は `${warnings}` で入れます。
3. 下のコマンドで動かし、画面の最終行と `echo "$?"` の数字を自分の目で見ます。

```bash
mkdir -p "$HOME/bash-lab/L5/site"
printf 'a\n' >"$HOME/bash-lab/L5/site/a.txt"
printf '%s\n' 'TARGET_DIR="$HOME/bash-lab/L5/site"' "CHECK_FILES='a.txt nothing.txt'" \
  >"$HOME/bash-lab/L5/check.conf"
chmod 600 "$HOME/bash-lab/L5/check.conf"
bash "$HOME/bash-lab/L5/report.sh" --config "$HOME/bash-lab/L5/check.conf"; echo "$?"
```

## 7. 完了条件

3つの状況で、最終行のレベル語と終了コードが次のとおりになることです。

| 状況 | 最終行のレベル語 | 終了コード |
|---|---|---|
| 警告0件（`CHECK_FILES` がすべてある） | `[OK]` | `0` |
| 警告2件（`CHECK_FILES` の2つが無い） | `[WARN]`（件数の `2` を含む） | `1` |
| 設定不正（`TARGET_DIR` が相対パス） | ―（`die` が終了2で止めます） | `2` |

## 8. 採点方法

採点器は次のことをします。隠しません。

- 答案をサンドボックス（使い捨てのディレクトリ）へ複製し、そこで実行します。元のファイルは変更しません。
- 採点のたびに、上の表の3つの設定ファイルと点検対象ディレクトリを **その場で作ります**。
- 本文を `grep -E` で静的に見ます（ケース名 `HARDCODED_EXIT`）。`EXIT_WARNING` の文字列があること、`exit 1` の直書き（正規表現 `exit[[:space:]]+1`）が無いことの2点です。
- 実行後、空行を除いた **最終行だけ** を取り出し、日時を伏せてからレベル語と件数を見ます。メッセージの言い回しは比べません。
- 終了コードは3つの状況それぞれで1件ずつ判定します。何件通ったかが分かります。

## 11. よくある誤り

| 症状 | 原因 | 対処 |
|---|---|---|
| `HARDCODED_EXIT` で落ちる | `exit 1` と直書きした | `exit "$EXIT_WARNING"` を使います。意味が読み手に伝わります |
| 警告0件でも最終行が出ない | 分岐の中で `exit` してから `log` を書いた | `log` を先、`exit` を後に書きます |
| 警告2件なのに終了0になる | `((warnings += 1))` が `set -e` の下で意図せず扱われた | `warnings=$((warnings + 1))` の形に変えると確実です |
