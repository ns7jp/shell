## H2 使う記号か関数名

`1` という数字は書きません。共通ライブラリの定数 `$EXIT_WARNING` を使います。
件数は `${warnings}` で文の中に入れます。分岐は `if ((warnings > 0)); then ... fi` です。

## H3 ほぼ答えの1行

```bash
if ((warnings > 0)); then
  log WARN "点検完了: 警告 ${warnings} 件"
  exit "$EXIT_WARNING"
fi
log OK '点検完了: 警告なし'
```

`log` が先、`exit` が後です。順番を入れ替えると最終行が出ません。
