# E13 作った後に読み直す（写経A）

| レベル | 5語 | 段階 | 目安 |

## 1. 一行目標

この問題で新しく覚えることは1個だけです。**「コマンドが成功した」と「成果物が読める」は別物です。**

## 2. 3行解説

- `[[ -s ファイル ]]` は「存在して、かつ0バイトでない」を確かめます。`-e` は存在するだけです。
- `tar -tzf アーカイブ` は中身の一覧を読み直します。読めなければ0以外を返します。
- 確かめた結果は必ず受け取ります。`|| die` を付けないと、確かめた意味がありません。

## 3. スパイン位置

**確かめる**（骨9要素の8番目「成果物の確認」）

## 6. 手順

1. まとめる材料を作ります。

```bash
mkdir -p "$HOME/bash-lab/L4/site"
printf '<html></html>\n' >"$HOME/bash-lab/L4/site/index.html"
```

2. `mkarc.sh` の「確かめる」にある `# TODO:` の2行を、`scripts/backup.sh` の46〜47行を見ながら2行に置き換えます。
3. 実行して終了コードを目で確かめ、この問題文の第13節の復習欄に「作っただけは未完成」と1行書きます。

```bash
bash "$HOME/bash-lab/L4/mkarc.sh" --src "$HOME/bash-lab/L4/site" --dst "$HOME/bash-lab/L4/arc"
echo "$?"
```

## 7. 完了条件

| 状況 | 終了コード | 出力 |
|---|---|---|
| 正常 | `0` | 標準出力に `[OK]` を含む行が出て、アーカイブが0バイトでない |
| 偽の `tar` を掴まされた | `2` | 標準エラーに **「アーカイブ」** を含む理由が出る |

`die` に渡すメッセージには「アーカイブ」という語を必ず入れます。言い回しは自由です。この語だけを見ます。

## 8. 採点方法

採点器は次のことをします。隠しません。

- 答案をサンドボックス（使い捨てのディレクトリ）へ複製し、そこで実行します。元のファイルは変更しません。
- 材料の `site/index.html` を採点のたびに作ります。
- **仕掛けを1つ使います。** サンドボックスの中の `fakebin` に「0バイトのアーカイブを作る偽の `tar`」を置き、通常のPATHの **先頭にそのディレクトリだけを足した** 環境でも実行します。あなたの環境の `tar` は変更しません。
- 判定は次の2組です。

| ケース名 | 実行する環境 | 見るもの |
|---|---|---|
| `NORMAL` | 通常のPATH | 終了コード `0` / 標準出力の `[OK]` / アーカイブが0バイトでないこと |
| `FAKE_TAR` | 偽の `tar` を先頭に足したPATH | 終了コード `2` / 標準エラーの「アーカイブ」 |

- 確認を書かずに終了コード0を返す実装は、`FAKE_TAR` で必ず不合格になります。
- `FAKE_TAR` で落ちたときは、不合格の表示に「この失敗は採点器の仕掛け（FAKE_TAR）のケースです」と出ます。

## 11. よくある誤り

| 症状 | 原因 | 対処 |
|---|---|---|
| `FAKE_TAR` で不合格 | `tar -tzf` の終了コードを見ていない（`die` の付け忘れ） | 確かめたら必ず結果を受け取ります |
| 0バイトのアーカイブが通ってしまう | `[[ -e ]]` と書いた | `-s` を使います。`-e` は「存在するだけ」で中身を見ません |
| `FAKE_TAR` の不合格を自分のバグだと思い込む | ケース名を読んでいない | 不合格の表示のケース名を先に読みます。仕掛けは第8節で開示しています |
