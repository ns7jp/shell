## H1 骨のどこか

骨9要素の8番目「成果物の確認」と9番目「ログと終了コード」です。
`E13`（確かめる）と `E16`（伝える）の予行演習にあたります。
見本の形は `scripts/build_verify.sh` の62〜67行と90〜94行です。

## H2 使う記号か関数名

「ある」は `[[ -e ファイル ]]`、「中身」は `[[ -s ファイル ]]` です。
「権限」は `stat -c '%a' "$file"` で取ります。結果は `644` という3桁の文字列です。
判定のたびに `log OK` か `log WARN` を出します。

## H3 ほぼ答えの1行

`warnings=0` で始め、`WARN` を出すたびに `((warnings += 1))` し、最後に分岐します。
`scripts/build_verify.sh` の90〜94行と同じ形です。

```bash
if (( warnings > 0 )); then
  log WARN "受け入れ試験完了: 警告 ${warnings} 件"
  exit "$EXIT_WARNING"
fi
log OK '受け入れ試験完了: 警告なし'
```

権限を取る行は `mode=$(stat -c '%a' -- "$target" 2>/dev/null || printf '取得できません')` です。
ファイルが無い状況でも止まらないように、失敗を受け止めます。
