## H1 骨のどこか

3ケースとは「ドライランで成果物ができないこと」「`--execute` で成果物ができること」「不明な引数で終了コード2になること」です。
雛形には1つ目の **成果物の検査だけ** がありません。そこが `__3__` です。

## H2 使う記号か関数名

被テストのパスは `"${TARGET_SCRIPT:-$HOME/bash-lab/L3/copyjob.sh}"` の形で受けます。直書きしません。
成果物の不在は `[[ ! -e パス ]]` で見ます。
`assert_contains` の中身は `grep -Fq -- "$needle" "$tmp_dir/output"` です。

## H3 ほぼ答えの1行

3か所はそれぞれ次のようになります。

```bash
target=${TARGET_SCRIPT:-$HOME/bash-lab/L3/copyjob.sh}
if grep -Fq -- "$needle" "$tmp_dir/output"; then ok "$name"; else not_ok "$name"; fi
if [[ ! -e "$tmp_dir/dst" ]]; then ok 'dry-run creates no file'; else not_ok 'dry-run creates no file'; fi
```

`CANNOT_FAIL` で落ちるのは、3行目を書いていないからです。
