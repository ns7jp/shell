# E15 白紙で受け入れ試験（白紙C）

## 1. 一行目標

この問題で新しく覚えることは1個だけです。**確かめる3点は、ある・中身・権限です。**

## 2. 3行解説

- 3項目とも確かめてから終了コードを決めます。1件目で止めると、残りが分かりません。
- 権限は `stat -c '%a' ファイル` で取れます。戻る値は `644` です。先頭に `0` は付きません。
- 警告を数えます。`warnings` が1件以上なら終了コード1、0件なら0です。

## 3. スパイン位置

## 6. 手順

1. `--dir DIR` を受け取り、`DIR/index.html` を対象にします。
2. 「ある」「中身」「権限が644」を **上から順に3項目とも** 確かめ、項目ごとに `log OK` か `log WARN` を出します。
3. 警告が1件以上なら `exit "$EXIT_WARNING"`、0件なら終了コード0で終わります。

```bash
mkdir -p "$HOME/bash-lab/L4/web"
printf '<html></html>\n' >"$HOME/bash-lab/L4/web/index.html"
chmod 644 "$HOME/bash-lab/L4/web/index.html"
bash "$HOME/bash-lab/L4/verify_dir.sh" --dir "$HOME/bash-lab/L4/web"; echo "$?"
```

## 7. 完了条件

4つの状況で、レベル語（`[OK]` / `[WARN]`）の並びと終了コードが次のとおりになることです。

| 状況 | レベル語の並び（上から3つ） | 終了コード |
|---|---|---|
| 正常（中身あり・権限644） | `[OK]` `[OK]` `[OK]` | `0` |
| `index.html` が無い | `[WARN]` `[WARN]` `[WARN]` | `1` |
| `index.html` が0バイト | `[OK]` `[WARN]` `[OK]` | `1` |
| 権限が666 | `[OK]` `[OK]` `[WARN]` | `1` |

## 8. 採点方法

採点器は次のことをします。隠しません。

- 答案をサンドボックス（使い捨てのディレクトリ）へ複製し、そこで実行します。元のファイルは変更しません。
- 4つのディレクトリを **採点のたびにその場で作ります**（正常0644／ファイルなし／空ファイル／権限0666）。gitは権限を保存しないため、権限は採点時に `chmod` します。
- 各実行の **標準出力** から `[OK]` と `[WARN]` を **上から3つだけ** 抜き出し、期待した並びと `diff -u` で比べます。4つ目以降（まとめの行など）は見ません。
- 終了コードも各実行で比べます。
- **メッセージ本文は一切比べません。** 日本語の言い回しの違いでは落ちません。

## 11. よくある誤り

| 症状 | 原因 | 対処 |
|---|---|---|
| レベル語の並びが短い | 1件目の `WARN` で終了し、残りを確かめていない | 3項目すべてを確かめてから終了コードを決めます |
| 権限のケースだけ不合格 | `stat -c '%a'` の結果を `0644` と比べた | 戻る値は `644` です。先頭の `0` は付きません |
| いつも終了コード0になる | 警告を数えていない | `warnings` を数え、最後に分岐します |
