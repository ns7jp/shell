# E14 落ちるテストを書く（穴埋めB）

| レベル | 5語 | 段階 | 目安 |
|---|---|---|---|
| L4 確かめる | 確かめる | B（穴埋め） | 45分 |

## 1. 一行目標

この問題で新しく覚えることは1個だけです。**価値があるのは、壊れたときに落ちるテストです。**

## 2. 3行解説

- テストは「終了コード」と「成果物の状態」の2つを見ます。片方だけでは足りません。
- ドライランのテストで見るのは、終了コード0だけではなく **成果物ができていないこと** です。
- 被テストのパスは環境変数で受けます。直書きすると、別の実装に当て直せません。

## 3. スパイン位置

**確かめる**（自分の書いた処理を、外から確かめる側に回ります）

## 4. 前提

- 前に合格しておく演習: `E12` `E13`
- 使うカード: `T3` `S3`

## 5. 作業場

```bash
source "$HOME/bash-lab/labenv.sh"
bash exercises/labctl.sh start E14
# 編集するファイル: $HOME/bash-lab/L4/my_tests.sh
```

## 6. 手順

1. `my_tests.sh` の `__1__` `__2__` `__3__` の3か所を埋めます。それ以外の行は変えません。
2. `E12` で書いた `copyjob.sh` に当てて、全部 `ok -` になることを確かめます。
3. わざと壊した実装に当てて、`not ok -` が出ることを確かめます。

```bash
bash "$HOME/bash-lab/L4/my_tests.sh"; echo "$?"
TARGET_SCRIPT="$LAB_REPO_DIR/exercises/answers/wrong/E12.wrong" bash "$HOME/bash-lab/L4/my_tests.sh"; echo "$?"
```

## 7. 完了条件

| 当てる実装 | 終了コード | 出力 |
|---|---|---|
| 正しい実装 | `0` | `not ok` が0件で、`ok - ` の行が3件以上 |
| わざと壊した実装 | `1` 以上 | `not ok` の行が1件以上 |

出力の形は `tests/run_tests.sh` の9〜10行と同じ `ok - 名前` / `not ok - 名前` です。

## 8. 採点方法

採点器は次のことをします。隠しません。

- 答案をサンドボックス（使い捨てのディレクトリ）へ複製し、そこで実行します。元のファイルは変更しません。
- **コメント以外の行に** 埋め残し（`__1__` などの文字列）が無いこと、`TARGET_SCRIPT` を使っていることを見ます。案内のコメントは消しても残しても構いません。
- **仕掛けを1つ使います。** 環境変数 `TARGET_SCRIPT` を切り替え、あなたのテストを2つの実装に当てます。

| ケース名 | 当てる実装 | 見るもの |
|---|---|---|
| `GOOD` | `exercises/answers/E12.ref.sh`（正しい実装） | 終了コード `0` / `not ok` が0件 / `ok - ` が3件以上 |
| `CANNOT_FAIL` | `exercises/answers/wrong/E12.wrong`（ドライランでもコピーしてしまう実装） | 終了コード `1` 以上 / `not ok` が1件以上 |

- `GOOD` だけ通って `CANNOT_FAIL` で落ちないテストは「落とせないテスト」として不合格にします。
- `CANNOT_FAIL` で落ちたときは、不合格の表示に「この失敗は採点器の仕掛け（CANNOT_FAIL）のケースです」と出ます。
- テストの名前（`ok - ` の右側）は一切比べません。日本語でも英語でも構いません。

## 11. よくある誤り

| 症状 | 原因 | 対処 |
|---|---|---|
| `CANNOT_FAIL` で不合格 | ドライランのあとの成果物の不在を検査していない | 壊れた実装が何をしてしまうかを考え、それを見つけるケースを足します |
| `GOOD` でも不合格 | `TARGET_SCRIPT` を使わずパスを直書きした | 環境変数から受けます |
| 集計が合わない | `ok` / `not ok` の綴りや区切りが違う | `tests/run_tests.sh` の9〜10行と同じ形にします |

## 12. 覚え方

`T3`「**学習の3段階は 写す→埋める→書く**」

この問題は2段目の「埋める」です。埋めるのは、通るテストではなく落ちるテストです。
