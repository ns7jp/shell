# E21 見ずに言えるかを確かめる（引き継ぎ）

| レベル | 5語 | 段階 | 目安 |
|---|---|---|---|
| L6 総合編 | — | — | 40分 |

## 1. 一行目標

この問題で新しく覚えることは1個だけです。**見ずに言えて、はじめて使えます。**

## 2. 3行解説

- 読んで分かるのと、何も見ずに言えるのは別です。
- 同じ日にまとめて3回やっても定着しません。日を変えて繰り返します。
- 台本にすると、順番が抜けている場所が自分で分かります。

## 3. スパイン位置

**伝える**（人に引き継ぐ側。骨9要素の9番目の外側にあたります）

## 4. 前提

- 前に合格しておく演習: `E19` `E20`
- 使うカード: `S1`〜`S5` `X0`〜`X2`

## 5. 作業場

```bash
source "$HOME/bash-lab/labenv.sh"
bash exercises/labctl.sh start E21
# 編集するファイル: $HOME/bash-lab/L6/talk.md
```

## 6. 手順

1. `bash exercises/labctl.sh recall` を、**日を変えて3回以上** 合格します。記録は `$HOME/bash-lab/progress/recall.log` に残ります。
2. `talk.md` に一分間の説明台本を書きます。`5語` `0` `1` `2` `ドライラン` `冪等` `証跡` の7語を **この順** に使います。
3. `bash exercises/labctl.sh progress --save` を実行し、進捗表を保存します。

```bash
bash exercises/labctl.sh recall
bash exercises/labctl.sh progress --save
```

## 7. 完了条件

| # | 見る場所 | 期待 |
|---|---|---|
| 1 | `progress/recall.log` | `[OK]` の行が3件以上ある |
| 2 | `progress/recall.log` | その合格日が2種類以上ある |
| 3 | `L6/talk.md` | 7語の **最初の出現** が指定の順に並んでいる |
| 4 | `progress/progress.md` | ファイルがあり、中身が空でない |
| 5 | `progress/progress.md` | `E01` から `E20` までの20行を含む |

## 8. 採点方法

採点器は次のことをします。隠しません。

- `recall.log` から、行頭が日付で `[OK]` を含む行を数えます。3件以上あるかを見ます。
- その行の先頭10文字（`YYYY-MM-DD`）を取り出して重複を除き、2種類以上あるかを見ます。**同じ日に3回まとめても通りません。**
- `talk.md` を上から走査し、7語それぞれが **最初に出てくる位置**（行番号と行内の位置）を取ります。その並びが昇順かだけを見ます。同じ行に並んでいても、行内の順が正しければ合格です。
- `progress.md` があり中身が空でないか、`| E01 |` から `| E20 |` までの20個が含まれるかを見ます。
- **文章の内容は読みません。** 日本語の言い回しの違いでは落ちません。
- 採点器はあなたの `recall` や `progress` を代わりに実行しません。記録が無ければ不合格になります。

- 7語を探すとき、**`#` で始まる見出し行は読み飛ばします**。見出しに `E21` と書いても数字が誤って数えられることはありません。

## 11. よくある誤り

| 症状 | 原因 | 対処 |
|---|---|---|
| 合格日が2種類に足りない | 同じ日に3回まとめて実施した | 日を変えて実施します。間隔をあけることが定着の条件です |
| 7語の順で落ちる | 見出しなどに `0` `1` `2` の数字を先に書いた | 見出しに数字を使わず、7語を書いた順のまま並べます |
| `progress.md` が無いと言われる | `progress --markdown` や引数なしで実行した | `--save` を付けます。画面表示だけでは保存されません |
