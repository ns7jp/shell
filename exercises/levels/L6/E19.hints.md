## H2 使う記号か関数名

借りる関数は `die` / `load_config` / `require_absolute_safe_path` / `require_integer_range` / `require_command` / `run_or_show` / `log` です。

アーカイブ名は次の形です。世代を残すので、ここは日時を付けます（`E11` の冪等とは目的が違います）。

```bash
archive_name="${ARCHIVE_PREFIX}_$(date '+%Y%m%d_%H%M%S').tar.gz"
```

## H3 ほぼ答えの1行

`tar` はこの形にします。`scripts/backup.sh` の42行目と同じです。

```bash
run_or_show "$execute" tar -C "$(dirname "$SOURCE_DIR")" -czf "$archive_path" -- "$(basename "$SOURCE_DIR")"
```

疑う順は次のとおりです。「ある」を最初に置かないと、4番のケースで未定義変数に先に当たります。

```bash
[[ -n ${SOURCE_DIR:-} ]] || die 'SOURCE_DIR は必須です'
[[ -n ${BACKUP_DIR:-} ]] || die 'BACKUP_DIR は必須です'
require_integer_range RETENTION_DAYS "$RETENTION_DAYS" 1 3650
require_absolute_safe_path SOURCE_DIR "$SOURCE_DIR"
[[ $BACKUP_DIR != "$SOURCE_DIR"/* ]] || die '保存先をバックアップ元の配下に置くことはできません'
```
