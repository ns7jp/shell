## H1 骨のどこか

スクリプトは書きません。3つの記録を残すだけです。

`recall` の記録（`progress/recall.log`）、台本（`L6/talk.md`）、進捗表（`progress/progress.md`）の3つです。

## H2 使う記号か関数名

打つコマンドは2つだけです。

```bash
bash exercises/labctl.sh recall          # 5語・終了コード・骨9要素を何も見ずに入力します
bash exercises/labctl.sh progress --save # 進捗表を progress/progress.md に書き出します
```

`recall` は答えを表示しません。`--save` を付けないと画面に出るだけで保存されません。

## H3 ほぼ答えの1行

`talk.md` はこの骨組みで書きます。7語を書いた順のまま並べるのがこつです。
見出しに `0` `1` `2` の数字を入れないでください。先に出た数字が数えられてしまいます。

```markdown
# 引き継ぎ台本（一分間）

- この案件は5語スパイン（受ける・疑う・動かす・確かめる・伝える）の順に書いています。
- 正常に終わったときは終了コード0を返します。
- 警告が残ったときは1を返します。
- 入力が不正なときは2で止めます。
- 変更する処理は既定でドライランにして、予定を見せてから実行します。
- 保存先の作成は冪等なので、二回動かしても同じ状態になります。
- 最後にログと証跡を残し、あとから誰でも確認できるようにします。
```

`recall` は日を変えて3回以上です。同じ日にまとめても合格日は1種類のままです。
