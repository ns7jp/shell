## H1 骨のどこか

バグは3種です。**引用符・終了コード・パイプ**。

`b1.sh` が引用符、`b2.sh` が終了コード、`b3.sh` がパイプです。
1本に1種類しか入っていません。他の場所は直さなくて構いません。

## H2 使う記号か関数名

- `b1.sh`: 変数展開を `"$var"` で囲みます。リダイレクト先も `>"$dir/file"` と囲みます。
- `b2.sh`: `$?` を対象コマンドの直後で受け取ります。今は間に `log` が入っています。
- `b3.sh`: 1行目の `set` に `pipefail` が効いているかを確かめます。

## H3 ほぼ答えの1行

`b1.sh` は次の2行です。

```bash
mkdir -p -- "$target"
printf 'ok\n' >"$target/report.txt"
```

`b2.sh` は「先に入れ物を用意して、対象コマンドの直後で受け取る」形にします。

```bash
status=0
tar -tzf "$archive" >/dev/null 2>&1 || status=$?
```

`b3.sh` は `set` の行に `pipefail` を足すだけです。`|| true` で握りつぶしてはいけません。

```bash
set -Eeuo pipefail
```
