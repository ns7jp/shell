# E20 壊れたスクリプトを直す（総合デバッグ）

| レベル | 5語 | 段階 | 目安 |
|---|---|---|---|
| L6 総合編 | — | — | 60分 |

## 1. 一行目標

この問題で新しく覚えることは1個だけです。**バグ3種は、引用符・終了コード・パイプです。**

## 2. 3行解説

- 引用符が無いと、空白の位置で1つの値が2語に分かれます。
- `$?` は直前だけを指します。間にコマンドを挟むと、その終了コードに変わります。
- `pipefail` が無いと、パイプは最後のコマンドの終了コードだけを返します。

## 3. スパイン位置

**確かめる**と**伝える**（骨9要素の8番目と9番目）。症状から原因へたどる練習です。

## 4. 前提

- 前に合格しておく演習: `E01` `E12` `E15`
- 使うカード: `T4` `X0` `X1`

## 5. 作業場

```bash
source "$HOME/bash-lab/labenv.sh"
bash exercises/labctl.sh start E20
# 直すファイル: $HOME/bash-lab/L6/b1.sh  b2.sh  b3.sh
# 編集するファイル: $HOME/bash-lab/L6/notes.md
```

`start E20` が壊れた3本を置きます。既にあるファイルは上書きしません。

## 6. 手順

1. 3本を1本ずつ実行し、**症状** を自分の目で見ます（推測で直しません）。
2. 3本を直します。バグは1本に1種類ずつ、合計3種類です。
3. `notes.md` に、b1・b2・b3 の3件分の「症状」「原因」「対処」を書きます。

```bash
mkdir -p "$HOME/bash-lab/L6/my data"
bash "$HOME/bash-lab/L6/b1.sh" --dir "$HOME/bash-lab/L6/my data"; echo "$?"
printf 'not a gzip\n' >"$HOME/bash-lab/L6/broken.tar.gz"
bash "$HOME/bash-lab/L6/b2.sh" --archive "$HOME/bash-lab/L6/broken.tar.gz"; echo "$?"
bash "$HOME/bash-lab/L6/b3.sh" --archive "$HOME/bash-lab/L6/broken.tar.gz"; echo "$?"
```

## 7. 完了条件

次の6件をすべて満たすことです。

| # | 対象 | 入力 | 期待 |
|---|---|---|---|
| 1 | `b1.sh` | 空白を含むディレクトリ名 | 終了コード `0`、成果物がちょうど1つ、`out/report.txt` がある |
| 2 | `b2.sh` | 壊れたアーカイブ | 終了コード `1` 以上 |
| 3 | `b2.sh` | 正常なアーカイブ | 終了コード `0` |
| 4 | `b3.sh` | 壊れたアーカイブ | 終了コード `1` 以上 |
| 5 | `b3.sh` | 正常なアーカイブ | 終了コード `0` |
| 6 | `notes.md` | — | 「症状」「原因」「対処」がそれぞれ3行以上 |

## 8. 採点方法

採点器は次のことをします。隠しません。

- `L6/b1.sh` `L6/b2.sh` `L6/b3.sh` をサンドボックス（使い捨てのディレクトリ）へ複製し、そこで実行します。元のファイルは変更しません。
- 教材を **採点のたびにその場で作ります**。空白を含むディレクトリ `my data`、正常な `good.tar.gz`、わざと壊した `broken.tar.gz` の3つです。壊れたアーカイブは gzip ではないただの文字列です。
- 判定は **1件1判定** です。落ちても「6 件中 n 件通過」と部分点が出ます。
- `notes.md` は `grep -c` で「症状」「原因」「対処」を数え、それぞれ3行以上あるかだけを見ます。**文章の中身は読みません。**
- 比べるのは **終了コードと成果物の状態** だけです。日本語の言い回しの違いでは落ちません。
- 3本が両方向（壊れた入力と正常な入力）で試されます。`exit 1` の決め打ちでは通りません。

## 11. よくある誤り

| 症状 | 原因 | 対処 |
|---|---|---|
| `b3.sh` が直ったように見えて採点で落ちる | `|| true` を足して失敗を握りつぶした | `pipefail` を有効にして、失敗を失敗のまま伝えます |
| `b2.sh` が直らない | `$?` の位置を変えず、後ろに `if` を足しただけ | `$?` は直前だけを指します。間にコマンドを挟みません |
| `notes.md` が不合格 | 3件分書かず1件で済ませた | b1・b2・b3 の3件それぞれに症状・原因・対処を書きます |
