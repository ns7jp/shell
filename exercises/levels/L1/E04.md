# E04 骨9要素を写す（写経A）

| レベル | 5語 | 段階 | 目安 |
|---|---|---|---|
| L1 受ける | 受ける | A 写経 | 30分 |

## 1. 一行目標

この問題で新しく覚えることは1個だけです。**どのスクリプトも、同じ9つの部品が同じ順に並びます。**

## 2. 3行解説

- 9つの部品を「骨9要素」と呼びます。並ぶ順は5語（受ける・疑う・動かす・確かめる・伝える）と同じです。
- 「9要素」であって「9行」ではありません。実物は40行前後になります。
- 写すのは手を動かすためです。コピー＆ペーストでは手が覚えません。

## 3. スパイン位置

**受ける**（骨全体を、受ける側から順に写します）

## 4. 前提

- 前に合格しておく演習: `E03`
- 使うカード: `T3`

## 5. 作業場

```bash
source "$HOME/bash-lab/labenv.sh"
bash exercises/labctl.sh start E04
# 編集するファイル: $HOME/bash-lab/L1/spine.sh
```

写経の問題なので、`start` は **空のファイル** を置きます。見本 `exercises/templates/spine.tmpl` は別の画面で開き、そこから手で写します。

## 6. 手順

1. 見本を別の画面で開いたままにします（`less exercises/templates/spine.tmpl`、`q` で閉じます）。
2. `$HOME/bash-lab/L1/spine.sh` へ、上から順に手で写します。1要素写すごとに、その要素が5語のどれかを声に出します。
3. `bash -n "$HOME/bash-lab/L1/spine.sh"` を実行し、何も出ないことを確かめます。

```bash
less exercises/templates/spine.tmpl
bash -n "$HOME/bash-lab/L1/spine.sh"
```

## 7. 完了条件

`bash -n` が通り、骨9要素がすべて `spine.sh` の中に見つかることです。

## 8. 採点方法

採点器は次のことをします。隠しません。答案は実行しません。

- 答案をサンドボックス（使い捨てのディレクトリ）へ複製します。元のファイルは変更しません。
- `bash -n` で構文を見ます。
- 9要素を1つずつ `grep -E` で探します。空白の入れ方の違いでは落ちません。

| 要素 | 探す手がかり |
|---|---|
| 1/9 shebang | `#!/usr/bin/env bash`（1行目） |
| 2/9 安全設定 | `set -Eeuo pipefail` |
| 3/9 共通ライブラリ読込 | `LAB_COMMON` |
| 4/9 usage | `usage()` |
| 5/9 引数解析 | `while (($#))` |
| 6/9 入力検証 | `die` |
| 7/9 ドライラン既定の処理 | `run_or_show` |
| 8/9 成果物の確認 | `[[ -s ` |
| 9/9 ログと終了コード | `exit` |

- 欠けた要素は、要素名を日本語で1件ずつ表示し、最後にまとめて列挙します。
- `shellcheck` があれば `-S warning` で警告が無いことを見ます。無い環境では `NOT RUN（shellcheck が未導入です）` と記録し、合格扱いにはしません。

## 11. よくある誤り

| 症状 | 原因 | 対処 |
|---|---|---|
| 2/9 の要素が見つからない | `set -eu` と短く書いた | `set -Eeuo pipefail` をそのまま写します |
| 3/9 の要素が見つからない | `source` の行を自分のパスに書き換えた | `"${LAB_COMMON:?}"` のまま写します |
| 全要素が揃ったのに E06 で書けない | コピー＆ペーストした | 手で写し直します。写経は手が覚えるための工程です |
