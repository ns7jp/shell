# E06 白紙から引数解析（白紙C）

## 1. 一行目標

この問題で新しく覚えることは1個だけです。**値を取る引数は、どれも同じ形にします。**

## 2. 3行解説

- `--config` も `--output` も値を取ります。だから書き方は同じ形の繰り返しです。
- 「値があるか」の確認は、値を取る引数の**すべて**に書きます。1つだけ書くのが一番多い失敗です。
- 「必須かどうか」の確認は `while` ループの**後**に書きます。ループの中では最後まで分かりません。

## 6. 手順

1. 変数を3つ用意します（`config_path` / `output_path` / `execute`）。
2. `while (($#))` と `case` で5分岐を書きます。`--config` `--output` `--execute` `-h|--help` `それ以外` です。
3. ループの後に `--config` の必須チェックを書き、最後に3つのキーを1行で出します。

```bash
bash "$HOME/bash-lab/L1/argparse2.sh" --config /opt/app/app.conf --output /opt/app/report.txt --execute
echo "$?"
```

## 7. 完了条件

下の6ケースで、終了コードが模範解答とすべて一致し、正常ケースで `config=` `output=` `execute=` の3キーが期待どおりに出ることです。

## 8. 採点方法

採点器は次のことをします。隠しません。差分テストです。

- 答案をサンドボックス（使い捨てのディレクトリ）へ複製し、同じ6ケースを**あなたの答案と `exercises/answers/E06.ref.sh` の両方**に流します。
- 比べるのは次の2点だけです。

1. 全6ケースの**終了コードが一致**すること
2. 正常ケースの出力に `config=` `output=` `execute=` の3キーが期待どおり現れること

| ケース名 | 与える引数 |
|---|---|
| `NORMAL` | `--config /opt/app/app.conf --output /opt/app/report.txt --execute` |
| `CONFIG_NO_VALUE` | `--config`（値なし） |
| `OUTPUT_NO_VALUE` | `--config /opt/app/app.conf --output`（値なし） |
| `UNKNOWN_ARG` | `--zzz` |
| `HELP` | `--help` |
| `NO_ARGS` | （引数なし） |

- **メッセージ本文・行順・そのほかの出力は比較しません。** 日本語の言い回しでは落ちません。
- 落ちたケース名を表示し、最後に `6ケース中 n 件通過` を出します。
- どのケースにも10秒の時間制限を掛けます。終わらなければ `TIMEOUT` として不合格にします。

## 11. よくある誤り

| 症状 | 原因 | 対処 |
|---|---|---|
| `OUTPUT_NO_VALUE` で落ちる | `--config` にだけ値の確認を書いた | 値を取る引数はすべて同じ形にします |
| `HELP` が終了2になる | `-h\|--help` の分岐が無く `*)` に落ちた | `case` の並びを確認します |
| `NO_ARGS` が終了0になる | ループの後の必須チェックが無い | `[[ -n $config_path ]] \|\| die '--config は必須です'` を書きます |
