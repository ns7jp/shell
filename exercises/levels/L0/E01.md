# E01 終了コードを自分の目で確かめる

| レベル | 5語 | 段階 | 目安 |
|---|---|---|---|

## 1. 一行目標

この問題で新しく覚えることは1個だけです。**コマンドは「成功したか」を数字で返します。**

## 2. 3行解説

- `$?` は **直前に終わったコマンド** の終了コードです。1つでも別のコマンドを挟むと値が変わります。
- `0` は無事、`1` は注意、`2` は無理。この3つだけ覚えます。
- `echo "$?"` は「その数字を画面に出す」という意味です。

## 3. スパイン位置

まだ5語には入りません。準備編です。

## 4. 前提

- 前に合格しておく演習: なし（ここが最初です）
- 使うカード: `X0` `X1` `X2`

## 5. 作業場

```bash
source "$HOME/bash-lab/labenv.sh"
bash exercises/labctl.sh start E01
# 編集するファイル: $HOME/bash-lab/L0/answer.txt
```

## 6. 手順

1. `true` を実行し、**その次の行で** `echo "$?"` を実行して数字を見ます。
2. 同じことを `false` と `bash "$LAB_FIXTURES/exit2.sh"` でも行います。
3. 見た数字を上から順に、1行1個で `answer.txt` に書きます。推測で書いてはいけません。

```bash
true
echo "$?"
false
echo "$?"
bash "$LAB_FIXTURES/exit2.sh"
echo "$?"
```

## 7. 完了条件

`answer.txt` の中身が、空行を除いて上から `0` `1` `2` の3行になっていることです。

## 8. 採点方法

採点器は次のことをします。隠しません。

- `answer.txt` を読み、空行と空白を取り除きます（全角数字は半角に直します）。
- 行数がちょうど3行かを見ます。
- 1行目から順に `0` `1` `2` と一致するかを見ます。
- 違った行だけを「期待= / 実測=」の2行で表示します。

## 11. よくある誤り

| 症状 | 原因 | 対処 |
|---|---|---|
| 1行目と2行目が入れ替わる | 推測で書いた | `true` と `false` を1つずつ実行し、そのたびに `echo "$?"` を打ちます |
| すべて `0` になる | 別のコマンドを挟んでから `$?` を見た | `$?` は「直前」だけを指します。対象コマンドの次の行で見ます |
| 見た目は合っているのに不一致 | 全角数字や余分な文字 | 半角で1行1文字だけ書きます |

## 12. 覚え方

`X0` `X1` `X2`「**0は無事、1は注意、2は無理**」
