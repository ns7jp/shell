# E02 5語スパインを backup.sh に接地させる

| レベル | 5語 | 段階 | 目安 |
|---|---|---|---|
| L0 準備編 | — | — | 20分 |

## 1. 一行目標

この問題で新しく覚えることは1個だけです。**5語は、実在するコードの場所を指す地図です。**

## 2. 3行解説

- 5語スパインは「受ける・疑う・動かす・確かめる・伝える」です。
- どのスクリプトも、この5つがこの順に並んでいます。
- 覚えるだけでは使えません。実物のどの行かを指させて、はじめて使えます。

## 3. スパイン位置

5語そのものを扱う問題です。

## 4. 前提

- 前に合格しておく演習: `E01`
- 使うカード: `S1`〜`S5`

## 5. 作業場

```bash
source "$HOME/bash-lab/labenv.sh"
bash exercises/labctl.sh start E02
# 編集するファイル: $HOME/bash-lab/L0/spine_map.tsv
```

## 6. 手順

1. `cat -n scripts/backup.sh` で全51行に行番号を付けて表示します。
2. 5語それぞれについて「ここだ」と思う行を1つ選びます。
3. `spine_map.tsv` に「語 行番号」を5行、5語の順に書きます（区切りは空白でもタブでも構いません）。

```text
受ける	16
疑う	28
...
```

## 7. 完了条件

5語が正しい順に並び、書いた行番号が本当にその語の処理を指していることです。

## 8. 採点方法

採点器は次のことをします。隠しません。

- 1列目が上から「受ける／疑う／動かす／確かめる／伝える」かを見ます。
- 2列目が 1〜51 の整数で、上から昇順（前の語より後ろ）かを見ます。
- 各行番号の **前後2行** を切り出し、次の手がかりがあるかを見ます。

| 語 | 探す手がかり |
|---|---|
| 受ける | `--config` |
| 疑う | `require_absolute_safe_path` / `require_integer_range` / `die` |
| 動かす | `run_or_show` |
| 確かめる | `tar -tzf` |
| 伝える | `log OK` / `exit` |

前後2行の幅を認めるので、1〜2行ずれても合格します。

## 9. 採点コマンド

```bash
bash exercises/labctl.sh grade E02
```

- H1: 骨のどこか

bash exercises/labctl.sh hint E02

## 11. よくある誤り

| 症状 | 原因 | 対処 |
|---|---|---|
| 「前の語より後ろ」で落ちる | 語の順番を入れ替えて書いた | 5語は必ず上から順です。表の並びを直します |
| 「手がかりが無い」で落ちる | 関数の定義側（`lib/common.sh`）を指した | `scripts/backup.sh` の中の **呼び出している行** を指します |
| 5行にならない | 見出し行やコメントを書いた | 5語の5行だけにします |

## 12. 覚え方

`S1`〜`S5`「**受ける・疑う・動かす・確かめる・伝える**」
