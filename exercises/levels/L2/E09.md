# E09 白紙で検証ブロック（白紙C）

| レベル | 5語 | 段階 | 目安 |
|---|---|---|---|
| L2 疑う編 | 疑う | C 書く | 55分 |

## 1. 一行目標

この問題で新しく覚えることは1個だけです。**疑う順は、ある→形→範囲→場所です。**

## 2. 3行解説

- 順番が命です。場所を先に疑うと、値が無いときに `set -u` で落ちて終了コードが `1` になります。
- 「ある」を通してから「形」「範囲」を見て、最後に「場所」を見ます。
- 場所の最後に「保存先がバックアップ元の配下でないこと」を足します。

## 3. スパイン位置

**疑う**（ある→形→範囲→場所 の4つすべて）

## 4. 前提

- 前に合格しておく演習: `E08`
- 使うカード: `T1` `M1` `M2` `M3`

## 5. 作業場

```bash
source "$HOME/bash-lab/labenv.sh"
bash exercises/labctl.sh start E09
# 編集するファイル: $HOME/bash-lab/L2/validate.sh
```

白紙です。`source` の行から下を自分で書きます。

## 6. 手順

1. `--config FILE` を受け、`load_config` で読み込むところまでを書きます（`scripts/backup.sh` の12〜23行と同じ形です）。
2. 「ある→形→範囲→場所」の順に検証を書きます。内容は次の表のとおりです。
3. すべて通ったら `log OK` を1行出して終了コード `0` で終わります。

| 順 | 疑うこと | 対象 |
|---|---|---|
| 1 ある | 空でないこと | `SOURCE_DIR` `BACKUP_DIR` `ARCHIVE_PREFIX` |
| 2 形 | `^[A-Za-z0-9._-]+$` に一致 | `ARCHIVE_PREFIX` |
| 3 範囲 | 1 から 3650 | `RETENTION_DAYS`（未設定なら 7 とみなします） |
| 4 場所 | 絶対安全パス、かつ保存先が元の配下でない | `SOURCE_DIR` `BACKUP_DIR` |

## 7. 完了条件

正常な設定で終了コード `0`、不正な設定で終了コード `2` になり、拒否理由が共通関数の出す文言であることです。

## 8. 採点方法

採点器は次のことをします。隠しません。

- 答案をサンドボックス（使い捨てのディレクトリ）へ複製し、そこで実行します。元のファイルは変更しません。
- 採点器が設定ファイルを **10個その場で作ります**（`chmod 600` を付けます）。内訳は次のとおりです。

| ケース名 | 仕込む内容 |
|---|---|
| `NORMAL` | すべて正常 |
| `MISSING_SOURCE` / `MISSING_BACKUP` / `MISSING_PREFIX` | 必須の1つを欠く |
| `BAD_FORMAT` | `ARCHIVE_PREFIX` に空白を入れる |
| `OUT_OF_RANGE` | `RETENTION_DAYS=5000` |
| `SYSTEM_DIR` | `SOURCE_DIR=/proc` |
| `NESTED` | `BACKUP_DIR` を `SOURCE_DIR` の配下に置く |
| `RELATIVE` | `SOURCE_DIR` を相対パスにする |
| `DOTDOT` | `SOURCE_DIR` に `..` を含める |

- 10ケースとも、あなたの答案と模範解答 `exercises/answers/E09.ref.sh` に **同じ引数** を流し、終了コードだけを比べます。日本語の言い回しでは落ちません。
- 拒否理由を見るのは3ケースだけです。`SYSTEM_DIR` は `重要なシステムディレクトリ`、`RELATIVE` は `空でない絶対パス`、`DOTDOT` は `.. は使用できません`。いずれも共通関数が実際に出す文言です。
- 静的検査として `eval` と `rm -rf` が本文に無いことを見ます。

> 危険なパスには、書き込みが必ず失敗する `/proc` を使います。検証をまだ書けていない答案を採点しても、実際のシステムは変更されません。

## 11. よくある誤り

| 症状 | 原因 | 対処 |
|---|---|---|
| `RELATIVE` だけ落ちる | 拒否理由を「重要なシステムディレクトリ」だと思い込んだ | 相対パスの文言は「空でない絶対パス」です。カード `M2` で覚えます |
| 必須欠落のケースで終了コードが `1` | 検証より先に値を使い、`set -u` で落ちた | 疑うは動かすより先です。「ある」を一番上に置きます |
| `NESTED` が通ってしまう | 一致（`!=`）だけを見た | 配下は `"$SOURCE_DIR"/*` のパターンで見ます |
