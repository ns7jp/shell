# E08 範囲チェックは共通関数を呼ぶ（穴埋めB）

| レベル | 5語 | 段階 | 目安 |
|---|---|---|---|
| L2 疑う編 | 疑う | B 埋める | 30分 |

## 1. 一行目標

この問題で新しく覚えることは1個だけです。**あるものは作らず借ります。**

## 2. 3行解説

- `require_integer_range 名前 値 最小 最大` は「形」と「範囲」を1行で疑います。
- 整数でなければ「整数で指定してください」、範囲外なら「1 から 65535 の範囲」と出して終了コード `2` で止まります。
- 同じ判定を2箇所に持つと、直すときに片方だけ直してずれます。だから借ります。

## 3. スパイン位置

**疑う**（ある→形→範囲→場所 の「形」と「範囲」）

## 4. 前提

- 前に合格しておく演習: `E07`
- 使うカード: `M4` `X2`

## 5. 作業場

```bash
source "$HOME/bash-lab/labenv.sh"
bash exercises/labctl.sh start E08
# 編集するファイル: $HOME/bash-lab/L2/port.sh
```

穴は1つだけです。`# TODO:` の行を1行で埋めます。

## 6. 手順

1. `sed -n '28,32p' scripts/lib/common.sh` を実行し、借りる関数の引数の順を目で確かめます。
2. `port.sh` の `# TODO:` の行を、その関数を呼ぶ1行に置き換えます。
3. 環境変数 `PORT` を変えて4回実行し、終了コードを自分の目で見ます。

```bash
PORT=80 bash "$HOME/bash-lab/L2/port.sh"; echo "$?"
PORT=70000 bash "$HOME/bash-lab/L2/port.sh"; echo "$?"
```

## 7. 完了条件

`PORT=80` で終了コード `0`、`PORT=0` と `PORT=70000` と `PORT=abc` で終了コード `2` になり、
判定を自分で書いていないことです。

## 8. 採点方法

採点器は次のことをします。隠しません。

- 答案をサンドボックス（使い捨てのディレクトリ）へ複製し、そこで実行します。元のファイルは変更しません。
- `PORT` を4通り与えて実行し、終了コードを見ます（`80`→`0`、`0`→`2`、`70000`→`2`、`abc`→`2`）。
- 範囲外の2ケースは出力に `1 から 65535 の範囲`、整数でないケースは `整数で指定してください` が含まれるかを見ます。この2つは共通関数が実際に出す文言です。
- **静的検査（ケース名 `REINVENTED`）**: 本文に `require_integer_range` があり、かつ `=~` と `^[0-9` が **無い** ことを見ます。判定を自作するとこの1件だけが落ちます。

## 11. よくある誤り

| 症状 | 原因 | 対処 |
|---|---|---|
| `REINVENTED` で落ちる | `[[ $PORT =~ ^[0-9]+$ ]]` を自分で書いた | 共通関数を呼びます。同じ判定を2箇所に持つと必ずずれます |
| 理由の文言が出ない | 引数の順を間違えた（名前と値が逆） | 名前・値・最小・最大の順です |
| `PORT` が空のとき変な動きをする | `"$PORT"` を引用符なしで渡した | 変数は裸で歩かせません |

## 12. 覚え方

`M4`「**「1 から 65535 の範囲」と出たら → require_integer_range が範囲外の値を拒否した**」
