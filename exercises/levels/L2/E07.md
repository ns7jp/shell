# E07 必須3項目を写す

| レベル | 5語 | 段階 | 目安 |

## 1. 一行目標

この問題で新しく覚えることは1個だけです。**無い設定は「無い」と言って止めます。**

## 2. 3行解説

- `[[ -n ${VAR:-} ]] || die 'VAR は必須です'` が「ある」を疑う型です。
- `${VAR:-}` の `:-` は「未定義なら空文字として扱う」という意味です。
- `die` は理由を出して終了コード `2`（無理）で止めます。書式は自作しません。

## 3. スパイン位置

**疑う**（ある→形→範囲→場所 の「ある」）

## 4. 前提

- 前に合格しておく演習: `E06`
- 使うカード: `S2` `X2`

## 5. 作業場

```bash
source "$HOME/bash-lab/labenv.sh"
bash exercises/labctl.sh start E07
# 編集するファイル: $HOME/bash-lab/L2/require3.sh
```

雛形には「受ける」まで書いてあります。あなたが写すのは「疑う」の3行だけです。

## 6. 手順

1. `cat -n scripts/backup.sh` を実行し、24〜25行を見ます。「ある」を疑う型はこの形です。
2. `require3.sh` の3つの `# TODO:` を、その型で1行ずつ置き換えます。変数名だけ変えます。
3. わざと1つ欠けた設定ファイルで実行し、終了コードを自分の目で見ます。

```bash
printf '%s\n' 'SOURCE_DIR=/srv/app' 'BACKUP_DIR=/var/backups/app' >"$HOME/bash-lab/L2/ng.conf"
chmod 600 "$HOME/bash-lab/L2/ng.conf"
bash "$HOME/bash-lab/L2/require3.sh" --config "$HOME/bash-lab/L2/ng.conf"
echo "$?"
```

## 7. 完了条件

3変数のうち1つでも欠けていれば終了コード `2` で欠けた変数名を表示し、3つそろえば終了コード `0` になることです。

## 8. 採点方法

採点器は次のことをします。隠しません。

- 答案をサンドボックス（使い捨てのディレクトリ）へ複製し、そこで実行します。元のファイルは変更しません。
- 採点器が設定ファイルを **4つその場で作ります**（`chmod 600` を付けます）。1つだけ欠けたものが3つと、3つそろったものが1つです。
- 欠けた3ケース（`MISSING_SOURCE` / `MISSING_BACKUP` / `MISSING_PREFIX`）は、終了コードが `2` か、出力に **欠けた変数名** が含まれるかを見ます。
- そろったケース（`ALL_PRESENT`）は終了コードが `0` かを見ます。
- 本文に3つの変数名があるかも見ます。日本語の言い回しは見ません。

## 11. よくある誤り

| 症状 | 原因 | 対処 |
|---|---|---|
| 終了コードが `1` になる | `${VAR:-}` の `:-` を落とし、`set -u` が先に落ちた | `${VAR:-}` の形で受けてから `die` します |
| 変数名が出力に出ない | `die` を `echo` と `exit` で自作した | 共通関数 `die` を使います。書式も終了コードもそろいます |
| 欠けていても終了コードが `0` | `||` を `&&` と書いた | 「空でなければ何もしない、空なら `die`」なので `||` です |
