# E12 白紙でドライラン既定（白紙C）

| レベル | 5語 | 段階 | 目安 |

## 1. 一行目標

この問題で新しく覚えることは1個だけです。**検証は `--execute` の有無に関係なく、必ず先に行います。**

## 2. 3行解説

- 検証を `--execute` のときだけにすると、ドライランが「何でも通る」ようになります。
- 順番は「受ける → 疑う → 動かす」です。疑うを飛ばして動かすへ行きません。
- 変更するコマンドは `run_or_show` に渡します。既定は安全側、危険は明示です。

## 3. スパイン位置

**動かす**（受ける・疑うの上に、ドライラン既定で載せます）

## 4. 前提

- 前に合格しておく演習: `E11`
- 使うカード: `S3`


## 6. 手順

1. 白紙から `copyjob.sh` を書きます。`--src DIR` `--dst DIR` `[--execute]` を受けます。
2. `while` ループを抜けた直後に検証を置きます。`--src` が読めること、`--dst` が絶対安全パスであること、`--dst` が `--src` の配下でないことの3つです。
3. コピーは `run_or_show` に渡します。ドライランで確かめてから `--execute` を付けます。

```bash
mkdir -p "$HOME/bash-lab/L3/src" && printf 'alpha\n' >"$HOME/bash-lab/L3/src/a.txt"
bash "$HOME/bash-lab/L3/copyjob.sh" --src "$HOME/bash-lab/L3/src" --dst "$HOME/bash-lab/L3/dst"
bash "$HOME/bash-lab/L3/copyjob.sh" --src "$HOME/bash-lab/L3/src" --dst "$HOME/bash-lab/L3/dst" --execute
diff -r "$HOME/bash-lab/L3/src" "$HOME/bash-lab/L3/dst"; echo "$?"
```

## 7. 完了条件

模範解答と5ケースで終了コードが一致し、ドライランの後に `--dst` が存在せず、`--execute` の後に `diff -r` が終了コード `0` になることです。

## 8. 採点方法

採点器は次のことをします。隠しません。

- 答案をサンドボックス（使い捨てのディレクトリ）へ複製し、そこにコピー元 `src`（`a.txt` と `sub/b.txt`）を作ります。元のファイルは変更しません。
- 本文に `eval` と `rm -rf` が無いことを見ます。
- 同じ引数を答案と模範解答 `exercises/answers/E12.ref.sh` の両方に流し、**終了コードだけ** を比べます。メッセージ本文は比べません。

| ケース名 | 渡す引数 |
|---|---|
| DRYRUN | `--src DIR --dst DIR` |
| EXECUTE | `--src DIR --dst DIR --execute` |
| MISSING_SRC | `--dst DIR`（`--src` を渡しません） |
| SYSTEM_DST | `--src DIR --dst /etc` |
| UNKNOWN_ARG | `--src DIR --dst DIR --bogus` |

加えて、答案だけを動かして2件を直接確認します。

| ケース名 | 見ること |
|---|---|
| DRYRUN_SIDE_EFFECT | ドライランの後に `--dst` が存在しないこと |

## 11. よくある誤り

| 症状 | 原因 | 対処 |
|---|---|---|
| ドライランなのに `--dst` ができる | `mkdir` を `run_or_show` の外に書いた | 変更するコマンドはすべて `run_or_show` 経由にします |
| `SYSTEM_DST` が終了コード `0` になる | 検証を `--execute` のときだけ行った | 検証は常に先に、無条件で行います |
| `diff -r` が終了コード `1` になる | `cp` の対象指定が違い、余計な階層ができた | `"$src/."` と `"$dst"` の組み合わせを確かめます |
