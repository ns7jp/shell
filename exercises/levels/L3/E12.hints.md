## H1 骨のどこか

骨9要素を1番から9番まで順に埋めるだけです。
`E06`（受ける）＋ `E09`（疑う）＋ `E10`（動かす）の組み合わせです。
検証は `while` ループを抜けた直後に置きます。`--execute` の分岐より **前** です。

## H2 使う記号か関数名

受けるは `while (($#))` と `case "$1" in` です。
疑うは `require_absolute_safe_path` と `[[ -d $src && -r $src ]]` です。
動かすは `run_or_show` です。コピーは `cp` を使います。

## H3 ほぼ答えの1行

```bash
run_or_show "$execute" mkdir -p -- "$dst"
run_or_show "$execute" cp -a -- "$src/." "$dst/"
```

`--dst` が `--src` の配下でないことは、`[[ $dst != "$src" && $dst != "$src"/* ]] || die ...` で見ます。
全文は `bash exercises/labctl.sh answer E12` で開けますが、開いた記録が残ります。
