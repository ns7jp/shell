# E11 2回実行しても同じ（穴埋めB）

| レベル | 5語 | 段階 | 目安 |
|---|---|---|---|
| L3 動かす | 動かす | B 埋める | 40分 |

## 1. 一行目標

この問題で新しく覚えることは1個だけです。**冪等とは「2回やって同じ」です。**

## 2. 3行解説

- 現場では、同じ手順が必ず2回目に流れます。2回目で壊れない書き方を冪等といいます。
- `mkdir -p` は、既にあってもエラーにしません。`install -D -m 0644` は、途中のディレクトリを作りつつ権限を固定して配置します。
- 名前にも中身にも日時や乱数を入れないことが要点です。入れると2回目に増えます。

## 3. スパイン位置

**動かす**（2回目でも結果が変わらない処理）

## 4. 前提

- 前に合格しておく演習: `E10`
- 使うカード: `S3`

## 5. 作業場

```bash
source "$HOME/bash-lab/labenv.sh"
bash exercises/labctl.sh start E11
# 編集するファイル: $HOME/bash-lab/L3/idem.sh
```

## 6. 手順

1. `idem.sh` を開きます。`__1__` と `__2__` の2か所だけを埋めます。ほかの行は変えません。
2. 同じ引数で **2回続けて** 実行します。
3. `find` でファイルの並びを2回見比べ、増えていないことを自分の目で確かめます。

```bash
bash "$HOME/bash-lab/L3/idem.sh" --dest "$HOME/bash-lab/L3/work"
find "$HOME/bash-lab/L3/work" -type f | sort
bash "$HOME/bash-lab/L3/idem.sh" --dest "$HOME/bash-lab/L3/work"
find "$HOME/bash-lab/L3/work" -type f | sort   # 上と1文字も違わないはずです
```

## 7. 完了条件

2回続けて実行して両方とも終了コードが `0` になり、`work` 配下の状態が1回目と2回目で完全に一致することです。

## 8. 採点方法

採点器は次のことをします。隠しません。

- 答案をサンドボックス（使い捨てのディレクトリ）へ複製し、そこの `work` を `--dest` に渡します。元のファイルは変更しません。
- 本文に `mkdir` と `install` があるかを見ます（穴に入る道具を指定しているためです）。
- 同じ引数で2回続けて実行し、次を見ます。

| ケース名 | 見ること |
|---|---|
| 1回目 / 2回目 | どちらも終了コード `0` |
| 成果物 | `work/conf/app.conf` が空でないこと、権限が `644` であること |
| NOT_IDEMPOTENT | 2回目にファイルが増えていないこと（増えていれば増えたファイル名を表示します） |
| 状態ハッシュ | 1回目終了後と2回目終了後で一致すること |

状態ハッシュは、`work` 配下のファイル名の一覧と各ファイルの `sha256sum` をまとめて `sha256sum` にかけた値です。日本語の言い回しは比べません。

## 11. よくある誤り

| 症状 | 原因 | 対処 |
|---|---|---|
| `NOT_IDEMPOTENT` で、2回目にファイルが増える | 出力ファイル名に `$(date ...)` を入れた | 世代を残す必要がないものに日時を付けません |
| ファイル数は同じなのに状態ハッシュが変わる | 中身に日時を書き込んだ | 中身も固定にします |
| 2回目に `mkdir` がエラーで落ちる | `mkdir` に `-p` を付けていない | `mkdir -p` を使います |
