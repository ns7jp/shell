# E10 run_or_show を写す（写経A）

| レベル | 5語 | 段階 | 目安 |
|---|---|---|---|
| L3 動かす | 動かす | A 写す | 30分 |

## 1. 一行目標

この問題で新しく覚えることは1個だけです。**変更するコマンドは `run_or_show` に渡します。**

## 2. 3行解説

- `run_or_show` は「先に言う、後でやる」を1行で書くための関数です。
- 第1引数が `false` のときは `[DRY-RUN]` と予定を出すだけで、何も変えません。
- 第1引数が `true` のときだけ、そのコマンドを実際に動かします。

## 3. スパイン位置

**動かす**（ドライランで見せてから処理する）

## 4. 前提

- 前に合格しておく演習: `E09`
- 使うカード: `S3`

## 5. 作業場

```bash
source "$HOME/bash-lab/labenv.sh"
bash exercises/labctl.sh start E10
# 編集するファイル: $HOME/bash-lab/L3/dry.sh
```

## 6. 手順

1. `dry.sh` を開きます。「受ける」と「疑う」は書いてあります。`# TODO:` の行を1行に置き換えます。
2. `--execute` を付けずに実行し、画面と `ls` の両方を見ます。
3. `--execute` を付けて実行し、同じ2つを見ます。違いを第13節に1行書きます。

```bash
bash "$HOME/bash-lab/L3/dry.sh" --dest "$HOME/bash-lab/L3/out"
ls -d "$HOME/bash-lab/L3/out"            # まだ無いはずです
bash "$HOME/bash-lab/L3/dry.sh" --dest "$HOME/bash-lab/L3/out" --execute
ls -d "$HOME/bash-lab/L3/out"            # 今度はあるはずです
```

## 7. 完了条件

`--execute` なしでは何も作られずに終了コードが `0`、`--execute` ありのときだけ `--dest` のディレクトリが作られて終了コードが `0` になることです。

## 8. 採点方法

採点器は次のことをします。隠しません。

- 答案をサンドボックス（使い捨てのディレクトリ）へ複製し、そこで実行します。元のファイルは変更しません。
- 本文に `run_or_show` があるかを見ます（写経の問題だからです）。
- サンドボックスの中の別々のパスを `--dest` に渡して、2回実行します。

| ケース名 | 渡す引数 | 見ること |
|---|---|---|
| DRYRUN | `--dest DIR` | 終了コード `0` / 標準出力に `[DRY-RUN]` |
| DRYRUN_SIDE_EFFECT | 同上 | その `DIR` が **存在しない** こと（あれば見た場所に表示します） |
| EXECUTE | `--dest DIR --execute` | 終了コード `0` / その `DIR` がディレクトリとしてあること |

日本語の言い回しは比べません。見るのは終了コードと、成果物があるか無いかだけです。

## 11. よくある誤り

| 症状 | 原因 | 対処 |
|---|---|---|
| `DRYRUN_SIDE_EFFECT` で落ちる | `run_or_show` を通さず `mkdir` を直接書いた | 変更するコマンドは必ず `run_or_show` 経由にします |
| `--execute` を付けても作られない | `execute` の値が `true` / `false` の文字列になっていない | 既定は `execute=false`、`--execute` で `execute=true` にします |
| 空白入りのパスで壊れる | `"$DEST"` の引用符を外した | 変数は裸で歩かせません。必ず二重引用符で囲みます |
