## H1 骨のどこか

骨9要素の7番目「処理」です。ここでは冪等（2回目に何も起きないこと）を作ります。
穴は2つだけです。`src` と `dst` は穴の外に用意してあるので、自分で決めません。

## H2 使う記号か関数名

`__1__` は `mkdir` です。`-p` を付けると、既にあってもエラーになりません。
`__2__` は `install` です。`-D` で途中のディレクトリを作り、`-m` で権限を固定します。

## H3 ほぼ答えの1行

```bash
mkdir -p -- "$dest"
install -D -m 0644 -- "$src" "$dst"
```

ファイル名に `$(date ...)` や `$RANDOM` を入れてはいけません。入れると2回目に増えます。
