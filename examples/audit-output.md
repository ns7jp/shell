# 監査出力の読み方

```text
2026-01-01T09:00:00+0900 [INFO] サーバー点検を開始します
2026-01-01T09:00:00+0900 [OK] メモリ使用率: 42% (しきい値: 80%)
2026-01-01T09:00:00+0900 [WARN] ディスク使用率 /: 85% (しきい値: 80%)
2026-01-01T09:00:00+0900 [WARN] 点検完了: 警告 1 件
```

これは説明用の架空例であり、実サーバーの実行証跡ではありません。`INFO` は情報、`OK` は基準内、`WARN` は確認が必要、`ERROR` は処理継続不能を表します。
